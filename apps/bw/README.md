# Hearthglance B/W

The Lua plugin for KOReader on the Kobo. It handles local clock updates, navigation through cached pages, user input and power behavior. Its Python renderer and LAN API are in `backend/kobo/`.

Install `hearthglance.koplugin/` under KOReader's `plugins/` directory. Supply device configuration separately on the Kobo. The Lua tests expect a KOReader runtime and its modules on the Lua path.
